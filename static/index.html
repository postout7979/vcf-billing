수집기(collector) 상태

collector는 별도 컨테이너로 동작하며, 이 화면은 등록된 연동 계정들의 마지막 동기화 기록을 집계해 간접적으로 보여주는 것입니다. 연동 계정별 상세 상태는 "계정 연동" 메뉴를 참고하세요.

데이터베이스

현재 이 애플리케이션이 사용 중인 데이터베이스 정보를 확인하고, 전체 데이터를 백업 파일로 내보내거나, 외부 PostgreSQL 서버로 데이터를 옮길 수 있습니다.

현재 DB 상태

엔진/접속 정보/전체 크기와 테이블별 행 수·크기를 확인합니다.

DB 내보내기 (백업)

PostgreSQL 사용 시 pg_dump SQL 덤프(psql로 복원), SQLite 사용 시 복원 가능한 .db 스냅샷 파일을 내려받습니다.

외부 PostgreSQL 연결

접속을 테스트하고, 현재 데이터를 외부 PostgreSQL로 복사(마이그레이션)합니다.

현재 연결된 데이터베이스

이 애플리케이션이 지금 실제로 쓰고 있는 DB 정보입니다.

테이블 행 수 크기

외부 PostgreSQL 연결

접속 테스트 및 데이터 마이그레이션

이 화면에서 접속을 테스트하고 현재 데이터를 외부 PostgreSQL로 복사(마이그레이션)할 수 있습니다. 다만 실제로 이 앱이 그 DB를 쓰도록 전환하는 것은 자동으로 되지 않습니다 — 이 컨테이너는 도커 소켓 권한이 없어 스스로 재시작할 수 없으므로, 마이그레이션이 끝나면 아래 안내대로 .env의 DATABASE_URL을 바꾸고 컨테이너를 직접 재시작해야 전환이 완료됩니다. 마이그레이션은 현재 DB를 읽기만 하므로 실패해도 기존 데이터는 영향받지 않습니다.
